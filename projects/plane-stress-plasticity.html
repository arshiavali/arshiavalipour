Research assistant work

As a student research assistant at CAM, I worked on extending our in-house stochastic finite element code for materials with local property variations, such as paper. My work included:

  • Plane-stress elasto-plasticity with different yield criteria, including Hill's anisotropic criterion.
  • Hardening models for isotropic and kinematic hardening.
  • Local variations: additional spatially varying material parameters that can be driven by random fields.

The in-house code is not public. The repository below is a standalone, open-source version of the plasticity part.

What it does

The code solves plane-stress elasto-plastic problems with the finite element method. A JSON input file defines the geometry, material and load case. The solver outputs field results over the load history, such as displacement, von Mises stress and equivalent plastic strain, together with the macroscopic stress–strain curve.

Material models

  • Elasticity: isotropic or orthotropic, with a material orientation angle.
  • Yield criteria: von Mises or Hill48 for anisotropic plastic behaviour.
  • Hardening: isotropic (linear or power-law) and linear kinematic hardening.

How it works

  • Local level (JAX): the constitutive update is an implicit return mapping solved with Newton's method at each integration point. The flow direction is obtained by automatic differentiation of the yield function, which makes it straightforward to add new yield criteria.
  • Consistent tangent: the algorithmic tangent is obtained by automatic differentiation instead of being derived by hand, which supports good convergence of the global Newton solver.
  • Implementation: the material update is compiled with jax.jit and vectorised over integration points with jax.vmap.
  • Global level (FEniCSx): a Newton–Raphson solver assembles the residual and Jacobian and solves the linear systems with PETSc.

Load cases

Tension, clamped tension and shear tests under displacement control. Results can be viewed in ParaView and exported as stress–strain curves.

What I took from it

Implementing plasticity at this level, rather than using a built-in material model in commercial software, requires understanding every step of a nonlinear FE solver, from the return mapping to the tangent and the global convergence.
