# Arshia Valipour – personal website

Source code of the personal website and research portfolio in computational mechanics and biomechanics.

**Live site:** https://arshiavali.github.io

## Contents

- **About**: background and research interests
- **Projects**: finite element work on fibre networks, stochastic FEM with random fields, anisotropic plasticity with FEniCSx and JAX, and ocular biomechanics
- **Experience**, **education** and **publications**
- **Contact**

## Structure

```
index.html        home page
projects/         one page per project
assets/           styling, images and animations
```

Plain HTML and CSS, no build step, hosted on GitHub Pages.
